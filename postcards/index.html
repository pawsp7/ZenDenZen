How to print

  1. Open the PDF, or one of the print pages above.
  2. Set the printer to 100% / actual size — do not fit to page.
  3. Use the exact-size PDF for a print shop, or the A4 sheet and cut on the crop marks.
  4. For a finished card, print front and back double-sided, flip on the short edge.
